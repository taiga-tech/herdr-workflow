# 元資料の保存

[文書目次](../docs/README.md) · [更新ルール](../docs/maintenance.md)

## 保存した元資料

`design-0.1.md`と`workflow-0.1.yaml`は、この会話で作成した元の設計書と設定例を内容変更せずに保存したもの。現行の参照先ではない。

| 元資料                        | 保存先                                 |
| ----------------------------- | -------------------------------------- |
| `herdr-workflow-design.md`    | [design-0.1.md](design-0.1.md)         |
| `herdr-workflow.example.yaml` | [workflow-0.1.yaml](workflow-0.1.yaml) |

SHA-256は[source-manifest.json](source-manifest.json)に記録した。元資料を更新せず、修正は分割後の主文書または現行の設定例へ加える。

元の章から現行文書への対応は[移行表](../docs/meta/source-map.md)を参照する。過去の記述を引用する場合は、文書版0.1の履歴を引用していることを明示する。
