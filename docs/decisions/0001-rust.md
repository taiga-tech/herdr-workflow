# ADR-0001：Rustの採用

[文書目次](../README.md) · [更新ルール](../maintenance.md)

この文書の管理対象：一つの判断の背景、選択と結果。現在の動作規則は関連仕様を参照する。

## 背景

worktreeの初期化からDAG、タスク監視、Herdr連携、停止と復旧までを統合するプラグインを作る。会話中に利用者がRustを選択した。

## 決定

実装言語をRustとする。この採用は利用者の明示的な決定に基づく。具体的なcrate、版、MSRVは別途確認する。

## 比較した案

Go、TypeScript、Python、Shellが前の検討に含まれていた。過去回答のプラグイン件数や言語人気の数値は、この決定の検証済み根拠として引き継がない。

## 結果と制約

Rustのビルド経路とOS別配布を用意する。Herdr本体と同じ言語であることだけを、プラグインAPIの互換性の根拠にしない。単一バイナリの配布でもGit、Herdr、mise、実行対象コマンドは別途必要になる。

## 確認記録

採用者：利用者。根拠：この会話の「rustにします」。元の決定日を推定して記載しない。記録日は本ファイルの`updated`。
